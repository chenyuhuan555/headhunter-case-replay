# 猎头卡单复盘

首批推荐被退回后，下一步是换人、补证据，还是重新对齐岗位？录入岗位条件、首批人选的脱敏经历和客户原话，查看建议下一步，编辑或复制追问，然后回填客户答复与最终处理。填写退回和澄清日期可计算自然日差；是否在澄清前重搜由顾问记录。

## 运行

在项目目录运行 `python -m http.server 4397 --bind 127.0.0.1 --directory dist`，访问 `http://127.0.0.1:4397/`。

运行 `node --test` 检查建议的证据边界、本机存储、日期计算和演练回放。

业务页用本地规则识别反馈线索。模糊或多线索的反馈只给出澄清建议，建议不能自动改岗位或判定人选。记录保存在当前浏览器和站点地址下，不调用模型、不上传、不跨设备同步，清除浏览器数据会删除记录。请使用岗位和人选代号，省略联系方式和可识别信息。「案例演练」保留三组虚构案例，与业务记录分开。

试用时先用脱敏旧单隐藏后续答复，比较建议有没有提前问到关键问题；再用新单观察澄清时长和澄清前是否重搜。日期差是实际记录，不代表节省的时间。
