# 猎头卡单复盘

首批推荐被退回后，下一步是换人、补证据，还是重新对齐岗位？这个独立原型用三个虚构案例回放这一刻。先读已知信息并选一个动作，再对照后续反馈，看这一步能解决什么、还有什么没问清。

## 运行

在项目目录运行 `python -m http.server 4397 --bind 127.0.0.1 --directory dist`，访问 `http://127.0.0.1:4397/`。

运行 `node --test replay.test.mjs` 检查揭晓条件、案例间状态隔离和重做。

案例与判断为预设内容，未调用模型，也未使用真实候选人资料。页面内的选择只保留在本次打开期间。

用真实业务验证时，可在脱敏旧单中隐藏后续反馈，先记录顾问原本会采取的动作，再比较复盘建议是否提前问到了关键问题。节省的工时和返工轮数需要在新单中记录。
